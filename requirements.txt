# Runtime dependencies, PINNED.
#
# An application, not a library: reproducible builds matter more than
# compatibility with whatever else is installed. `fastapi>=0.115` meant an
# upstream release could ship itself into a container build with no review,
# and the first anyone knew was a behaviour change in production.
#
# Transitive pins are included so the image is byte-reproducible. Dependabot
# opens a PR per bump and CI runs the full suite against it, which is the
# review this used to skip.
#
# numpy-only for math — no torch, no transformers, no sentence-transformers
# (docs/DECISIONS.md D6: Ollama serves embeddings over HTTP, so a second
# inference runtime would just compete for scarce RAM).
#
#   .venv/bin/pip install -r requirements.txt
